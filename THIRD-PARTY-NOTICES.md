# Third-party notices

The extension ships no third-party code. The .reg reader and writer, the syntax grammar, the hive reader, the comparison and the exports are written for this extension, the hive reader from public notes on the registry hive format (base block, hive bins, key, value and list cells). No code from other registry tools is used.

## Sample files

samples/zovo-demo.reg and samples/zovo-demo.hiv hold the settings of a made-up app. They were written for this extension by scripts/make-samples.js (MIT, like the extension).
