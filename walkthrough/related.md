# Free Zovo extensions for other Windows files

- Hex Viewer shows the bytes of any file, hives and .dat files included.
- ELF & PE Viewer opens .exe and .dll files with their headers, sections and imports.
- Log Viewer opens large .log files, filters them by level, text and time, and follows a file that is still growing.

Each link opens the extension page. Nothing installs until you click Install there.
