# Registry hives

- Right-click a hive in the Explorer (NTUSER.DAT, UsrClass.dat, SYSTEM, SOFTWARE, SAM) and pick Open as Registry Hive. Files ending in .hiv open directly.
- The file must start with "regf". Other files get a short note, and no tab opens.
- Hives open read-only. A hive that was not closed cleanly opens as it is on disk, with a note.
